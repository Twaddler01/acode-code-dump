# Code Dump

A simple Acode plugin for collecting project source files into a single text file.

## Features

- Select a project folder.
- Display the selected folder.
- More source-file collection features are planned.

## Getting Started

1. Install Code Dump in Acode. Add from within Acode (local): plugin.zip.
2. Open Code Dump using its sidebar icon.
3. Select the project folder you want to work with.

## Features

- Recursive folder scanning.
- Configurable file extensions.
- Excluded files and folders.
- Generate a single text file containing file paths and contents.
- Copy the generated dump to the clipboard.

## Development

Code Dump is built as a JavaScript plugin for the Acode editor.

## To build the plugin from source, run:

```bash
npm install
npm run build
```
